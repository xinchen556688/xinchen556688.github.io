How to Write a Museum Wall Label That Works for Visitors

Museums have written wall labels for well over a century. Screen readers and search crawlers arrived much more recently, and both needed something the traditional label never provided: a description that works without the image in front of you.

That gap is where most accessibility and SEO problems start. The fix is not to write more text. It is to write the right text for each of the three places an image description gets used.

This note is part of a series on image descriptions for public-facing sites, published via GitHub Pages.
