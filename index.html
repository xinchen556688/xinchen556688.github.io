AutoImageAnnotation

Notes on turning one photograph into four different kinds of text — and why you can't use the same paragraph for all of them.

Museum cataloguers, archive staff, and accessibility teams keep running into the same problem: an image needs text, and the text needs to serve at least four audiences at once. A visitor reading a wall label in a gallery. A screen reader announcing an image to someone who can't see it. A search engine deciding what the image is about. A social feed where the caption has three seconds to earn attention.

These are not the same text. Treating them as one produces something that half-works everywhere: too long for a caption, too thin for a label, too vague for alt text, too verbose for a search snippet.

The four outputs

Wall label Title, medium, date, and a short interpretive body — the gallery voice, written for someone standing in front of the object.
Description A prose paragraph for catalogues and finding aids: what is depicted, how it's composed, what a careful viewer would notice.
Alt text One or two sentences for screen readers. Functional, not poetic. Describes the information, not the atmosphere.
Caption Platform-shaped. Short, direct, written to survive being skimmed in a feed.

What the tool does

AutoImageAnnotation takes an uploaded image and produces all four of the above. The wall label generator lives at the museum wall label service, which offers eight visual styles — from academic curator to children's gallery — because the register of a label changes entirely depending on which room it hangs in.

The part that matters is not the generation. It's that each output is written against a different constraint. Alt text that describes brushwork is a failure. A wall label that reads like alt text is a worse one.

Why this page exists

This is a small static site documenting the reasoning behind the tool, kept separate from the application itself so the notes can be read without signing up for anything. If you work with image collections and have opinions about how labels should read, the notes here are the part worth arguing with.
