The Three Layers of Image Description, Explained

Every image published on a public-facing site ends up needing at least three separate descriptions, and they are not interchangeable. One is read by a visitor standing in front of the work. One is read aloud by a screen reader. One is read by a search engine deciding what the page is about.

Writing all three is not extra work if you understand that each answers a different question. This guide walks through what those questions are and how the same underlying information gets reshaped for each audience.

This note is part of a series on image descriptions for public-facing sites, published via GitHub Pages.
