The Practical Guide to Artwork Image Descriptions

The most common image description mistake is not writing a bad one. It is writing one good description and pasting it into three different fields that each need something else entirely.

A label that reads beautifully on a gallery wall will sound clumsy when a screen reader announces it, and a caption optimised for search will tell a blind visitor nothing useful. Here is how to tell the three apart.

This note is part of a series on image descriptions for public-facing sites, published via GitHub Pages.
